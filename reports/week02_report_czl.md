# 第2周任务配置与二维状态仿真周报

## 1. 本周任务

本周主要完成无人机任务配置读取和二维运动仿真。

主要工作包括：

1. 建立无人机任务 JSON 配置文件；
2. 使用 Python 读取任务配置；
3. 检查任务配置中的必要字段；
4. 根据起点、终点和速度生成二维直线轨迹；
5. 记录每个时间步的位置、速度和任务进度；
6. 将真实轨迹保存为 CSV 文件；
7. 绘制地图、障碍物、起点、终点和真实轨迹；
8. 修改任务参数，并验证程序能够根据新的任务配置自动生成新的轨迹。

## 2. 任务配置

本周使用的任务配置文件为：

`configs/mission_bridge_czl.json`

任务配置中包含以下参数：

- 地图大小：67 × 67；
- 起点：[6, 6]；
- 速度：1.0；
- 安全距离：1.0；
- 障碍物：一个矩形障碍物。

障碍物范围为：

- xmin = 8
- xmax = 12
- ymin = 7
- ymax = 13

程序运行时没有把这些任务参数直接写死在 Python 程序中，而是从 JSON 配置文件中读取。

因此，当起点、终点或其他任务参数发生变化时，可以只修改 JSON 文件，而不需要修改仿真程序。

## 3. 程序实现

### 3.1 mission_io.py

`mission_io.py` 主要负责读取和检查任务配置。

程序首先使用 `Path` 获取当前项目的根目录，然后根据项目内部的相对位置找到任务文件：

`configs/mission_bridge_czl.json`

之后使用 `json.load()` 将 JSON 文件中的内容读取到 Python 中，并转换为字典形式。

程序还会检查以下必要字段是否存在：

- map_size
- start
- goal
- speed
- safety_distance
- obstacles

如果任务配置中缺少必要字段，程序会主动给出错误提示。

通过这种方式，可以在进入二维仿真之前，先检查任务文件是否完整。

---

### 3.2 simulator_2d.py

`simulator_2d.py` 主要负责二维运动仿真、数据记录和轨迹绘制。

程序首先调用 `mission_io.py` 中的 `load_mission()` 函数读取任务配置。

读取起点和终点后，计算两个方向上的位移：

dx = goal_x - start_x

dy = goal_y - start_y

然后根据勾股定理计算起点到终点之间的直线距离：

distance = sqrt(dx² + dy²)

之后将任务配置中给定的总速度分解为 X 和 Y 两个方向的速度：

vx = speed × dx / distance

vy = speed × dy / distance

程序按照固定时间间隔计算无人机当前位置：

x = start_x + vx × time

y = start_y + vy × time

同时计算任务完成进度：

task_progress = time / total_time

其中：

- task_progress = 0 表示任务刚开始；
- task_progress = 1 表示已经到达终点。

程序最终记录以下数据：

- time
- x
- y
- vx
- vy
- target_id
- task_progress

这些数据使用 Pandas 保存为 CSV 文件。

最终轨迹数据为：

x = 50

y = 20

## 8. 当前存在的问题

当前程序已经能够完成基本的二维直线运动仿真，但仍然存在一些明显的局限。

目前程序只根据起点和终点生成直线路径。

虽然任务配置文件中已经包含障碍物，并且程序能够在地图上正确绘制障碍物，但目前还没有实现真正的避障和路径规划功能。

因此，如果直线路径经过障碍物，当前程序仍然会直接穿过障碍物。

当前程序暂时还没有实现以下功能：

- 障碍物碰撞检测；
- 自动绕开障碍物；
- A* 等路径规划算法；
- 传感器观测误差；
- 数据缺失和异常观测；
- 状态估计；
- 状态可靠性判断；
- 根据可靠性进行减速、悬停或重新规划。

本周重点是完成任务配置读取和基础二维状态仿真，因此上述功能将在后续训练中继续实现。

之后使用 PyCharm 自动创建 `.venv` 虚拟环境，使当前项目可以独立安装和管理 Python 第三方库。

### 9.3 运行了错误的 main.py

PyCharm 最开始保留了自动生成的 `main.py` 运行配置。

删除 `main.py` 后，直接点击原来的运行按钮会出现找不到文件的问题。

之后改为直接运行 `mission_io.py` 和 `simulator_2d.py`，问题解决。

### 9.4 将 pip 命令输入到了 Python 控制台

第一次安装 Pandas 和 Matplotlib 时，将：

`python -m pip install pandas matplotlib`

输入到了 Python Console 中，因此出现 SyntaxError。

之后使用 PyCharm 的 Terminal，在 PowerShell 环境中重新执行该命令，成功安装了 Pandas 和 Matplotlib。
